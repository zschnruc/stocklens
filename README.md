# 研值 · StockLens

一个双击就能用的股票研报与研判工具，单文件 HTML，无需安装、无需后端。

## 核心功能

输入股票名称或代码，自动生成一份研判页：

1. **个股研报**：最近 6 个月研报，含机构、分析师、评级、目标价、PDF 原文链接。
2. **行业研报**：个股所属行业的最近 6 个月研报。
3. **同业对比**：行业内总市值最大的 3 只、归母净利润最高的 3 只股票，以及各自最近研报。
4. **K 线图**：klinecharts 引擎渲染蜡烛图，支持拖拽平移、滚轮缩放、日/周/月切换、MA20/MA60 均线、成交量/MACD/KDJ/RSI 副图与布林带叠加、十字光标 OHLC 详情；分析师目标价以虚线锚定图上。
5. **打分研判**：研报与机构评级、盈利与成长、技术面动量、新闻舆情四个维度合成 100 分，并给出结论、依据和风险提示。
6. **自选股**：研判页一键加自选，首页展示自选股现价与涨跌速览（本地保存，上限 20 只）。

## 市场支持

| 市场 | 行情/K线 | 个股研报 | 行业研报 | 同业对比 | 财务成长 | 新闻舆情 | 打分 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| A 股 | 支持 | 支持 | 支持 | 支持 | 支持 | 支持 | 完整 |
| 港股 | 支持 | 暂无免费源 | 仅 A 股同名行业参考 | 市值/利润榜 | 尽力获取 | 支持 | 按可用维度折算 |
| 美股 | 支持 | 暂无免费源 | 仅 A 股同名行业参考 | 市值/利润榜 | 尽力获取 | 支持 | 按可用维度折算 |

> 东方财富免费研报接口仅覆盖 A 股；港股/美股暂无稳定的免费中文研报源，页面会明确标注"暂无数据"，不会用假数据填充。

## 数据来源

- **行情与 K 线**：腾讯财经公开行情接口（A / 港股 / 美股）
- **研报**：东方财富研报中心（JSONP）
- **财务指标**：东方财富 Choice F10 公开接口
- **新闻**：东方财富资讯搜索
- **行业与同业**：东方财富行业板块接口（A 股）；港股/美股按行业标签筛选

所有请求均由浏览器直接发起，不上传任何个人数据。接口为公开网页接口，可能因对方限流或调整而暂时不可用。

## 评分体系（100 分）

| 维度 | 权重 | 主要指标 |
| --- | --- | --- |
| 研报与机构评级 | 30 | 近 6 个月研报数量、买入/增持占比、评级上调、目标价空间 |
| 盈利与成长 | 25 | 营收同比、归母净利同比、ROE |
| 技术面动量 | 25 | 20/60/120 日涨跌幅、均线位置、波动率 |
| 新闻舆情 | 20 | 最近新闻正负面关键词占比、时效性 |

某一维度数据缺失时，按剩余可用维度折算为百分制，并在页面标注，不臆造数据。

## 运行

```bash
# 直接双击 index.html，或：
open index.html
```

开发命令：

```bash
node scripts/build.js    # 把 src 内联成单文件 index.html
node scripts/check.js    # 产物检查：单文件、无外链、无残留占位符
node scripts/test-candle.js   # K 线模块冒烟测试，引擎无关（需联网）
```

建议使用最新版 Chrome / Edge / Safari。
